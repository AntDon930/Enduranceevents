Leonida Clips – Privacy Policy

Last updated: 11 November 2026

Leonida Clips is a private tool operated by Anton Donauer. It prepares short gaming clips and uploads them to the operator's own YouTube channel (@Leonida.Clipzzz). It is not offered to the public.

Google user data we access

Through the YouTube Data API, Leonida Clips accesses only the operator's own YouTube account in order to upload videos, set their title, description and publish time, and read view and like counts of those videos. No data of other Google users is accessed.

How the data is used and stored

The access token is stored only on the operator's own server and is used exclusively to manage the operator's channel. Video statistics are stored in a local database to see which clips perform well. Data is not sold, shared with third parties or used for advertising.

Leonida Clips' use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Stored data is deleted on request.
